# Decisions

Architecture decision records (ADRs) for choices that cross threads or areas, or that someone might later reverse without knowing why.
Each file is `NNNN-short-title.md`.
An accepted ADR is never edited, except for its Status line when a newer ADR supersedes it.
To change a decision, write a new ADR that supersedes the old one.
With the threads plugin, `/threads:adr <title>` writes one and updates this index.
